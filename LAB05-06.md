## Những thành phần đã triển khai

- **Backend:** Render Web Service `mern-backend-236435`, image `phantuananhnct/mern-backend:latest` (cùng nội dung với tag `2.0`), cổng 5000. `MONGODB_URI` nằm trong Environment Group `MERN-Production-Secrets` chỉ liên kết với backend; `CLIENT_URL` nằm trong Environment riêng của service. Endpoint `/health` trả trạng thái và thời gian chạy. CORS chỉ chấp nhận domain frontend và localhost.
- **Frontend:** Render Web Service `mern-frontend-236435`, image `phantuananhnct/mern-frontend:latest` (cùng nội dung với tag `3.1`; tag `3.0` vẫn lưu bản đầu của Buổi 6), Nginx cổng 80; `BACKEND_URL` ở Environment trỏ đến URL backend. React gọi đường dẫn tương đối `/api/students`; Nginx chuyển tiếp `/api/` sang backend. Như vậy UI và API dùng một domain công khai.
- **Tự triển khai:** mỗi repository Docker Hub có webhook riêng trỏ đến deploy hook tương ứng trên Render. URL hook là bí mật, không ghi trong repository. Lịch sử Docker Hub ngày 08/10/2026 ghi hai lần gọi webhook thành công, HTTP 200.
- **Docker local:** `docker-compose.production.yml` chạy cùng hai tag phiên bản cố định, dùng `BACKEND_URL=http://backend:5000` trên Docker network. `docker-compose.hub.yml` tiếp tục giữ cấu hình Buổi 4.

## Các lệnh kiểm tra và phát hành

```sh
docker build -t phantuananhnct/mern-backend:2.0 ./server
docker build -t phantuananhnct/mern-frontend:3.1 ./client
docker push phantuananhnct/mern-backend:2.0
docker push phantuananhnct/mern-frontend:3.1
docker tag phantuananhnct/mern-backend:2.0 phantuananhnct/mern-backend:latest
docker tag phantuananhnct/mern-frontend:3.1 phantuananhnct/mern-frontend:latest
docker push phantuananhnct/mern-backend:latest
docker push phantuananhnct/mern-frontend:latest
curl https://mern-frontend-236435.onrender.com/api/students
curl https://mern-backend-236435.onrender.com/health
```

Đã kiểm tra GET, POST, PUT và DELETE qua domain frontend, tức là qua Nginx rồi đến backend và Atlas. Sinh viên dùng để thử đã được xóa sau kiểm tra. Hai endpoint health trả HTTP 200. Render Free có thể cần thời gian khởi động sau khi không có truy cập.

## Mục chưa xác nhận trên giao diện

- Buổi 6 câu 66–69: đã tạo Environment Group, chuyển `MONGODB_URI` vào nhóm và liên kết với backend. Sau khi bỏ biến trùng ở service, backend vẫn báo `UP` và API trả dữ liệu.
- Buổi 6 câu 72–84: đã mở Logs, thấy kết nối MongoDB và các request `/health`, `/api/students` trả HTTP 200. Đã mở Metrics; gói Render Free hiển thị bandwidth, còn biểu đồ CPU/RAM yêu cầu nâng cấp trả phí. Chưa thực hiện riêng thao tác Manual Redeploy/Clear Build Cache hoặc lưu ảnh theo từng câu.
- Những câu yêu cầu ảnh màn hình riêng cần ảnh chụp trực tiếp tại thời điểm thao tác. Tài liệu này ghi trạng thái và link kiểm tra, không dùng ảnh cũ để thay cho minh chứng hiện tại.

## Ghi chú đối chiếu đề

Vite đóng gói `VITE_*` khi build; đổi `VITE_API_URL` ở Environment của một image đã build sẽ không sửa JavaScript. Bản triển khai dùng đường dẫn tương đối và Nginx template để cấu hình backend lúc container chạy. Quy tắc Rewrite trong dashboard Render dành cho Static Site; frontend ở đây là Web Service chạy Docker image nên cấu hình proxy ở Nginx.

Theo yêu cầu làm gộp, mã nguồn Buổi 5–6 và phần sửa cần thiết được đưa lên trong **một commit mới**. Vì vậy lịch sử Git không có từng commit trung gian tương ứng mỗi bước trong đề; các tag Docker Hub vẫn cho phép đối chiếu các mốc image.
